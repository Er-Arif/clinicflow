- adaptive-icon-foreground.png
- adaptive-icon-monochrome.png
- splash-icon.png
- favicon.png
- notification-icon.png
- notification-icon-master.png
- clinicflow-logo-mark.png
- clinicflow-mark-simplified.png
- clinicflow-lockup.png
- splash-lockup-white.png

Brand:
ClinicFlow
Appointments · Payments · Follow-ups

Use full branding mainly on Splash, Login and About. Keep appointment/payment/follow-up workflow screens minimally branded.

See `expo-app-config-snippet.json`. If the project already uses the `expo-splash-screen` config plugin, wire the same image/background into that existing configuration instead of adding a second splash configuration.
